## 1차 — AX 플랫폼 도입 (2026.04 – 2026.06)

AKeeON 기본 스펙인 **사규검색 Agent(RAG)** 에 더해, 현업 인터뷰로 발굴한 추가 니즈를 바탕으로 Agent 2종을 설계하고, 그중 SAP SD AI Agent를 구현했습니다.

- **SAP CO AI Agent** — SAP CO(관리회계) 모듈 연동, 원가·수익성 데이터를 자연어로 조회·집계하여 경영진 회의 보고서 작성, 계획 대비 실적 증빙
- **SAP SD AI Agent** — SAP SO 모듈 연동, 자연어로 오더/납품문서 조회, 생성, 삭제, 수정 및 자재/판매처 조회

역할: **PL**, 현업 인터뷰를 통한 Agent 니즈 발굴, Agent 시나리오 설계, 결과보고 및 현업 설명회 진행

성과: 1차 성공적 완료 → **2차 프로젝트 수주**로 연결

## 2차 — Public LLM 확장 (2026.07 – 2026.12, 진행 중)

목적별 RAG·Agent에 머물던 1차 AX 플랫폼을 범용 AI 업무 환경으로 확장합니다.

- **Public LLM 멀티 모델** — Claude · GPT · Gemini 등 퍼블릭 모델을 한 화면에서 선택해 답변 수신
- **웹 검색 · 딥리서치** — 업무 자료용 이미지 생성
- **파일 분석 · 생성** — 문서·엑셀 분석·요약 및 결과 문서 생성
- **LLMOps** — 토큰·비용 모니터링, 품질 피드백, 모델·프롬프트 관리
