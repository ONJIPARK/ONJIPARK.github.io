## 개요

사내 복지·인사·규정·매뉴얼 문서 기반 대화형 AI 서비스로 시작해, 2026년 그룹사·대외 판매가 가능한 AX 플랫폼(AI Hub · Orchestrator)으로 확장했습니다. 외주 참여 없이 AX사업팀이 자체 개발했고, 1년여 만에 애경그룹의 AX 플랫폼으로 자리잡았습니다.

## 역할

- **초기 구축(AI Hub)** — Azure OpenAI/AI Foundry + AWS Bedrock LLM 연동, 공통 RAG 모듈, Agent 실행 구조 설계 및 개발 + DB 스키마 설계·구축
- **사업 기획** — 제품소개서, 가격 모델(라이선스 + Agent 모듈 + 유지보수), 솔루션 소개 영상 기획·편집, 계약 프로세스 수립
- **관리자 페이지(AKeeON Admin)** — 권한·파일·비용·대시보드 파트 총괄, 화면 기획 및 백엔드 개발

## 성과

- 계열사·대외 고객 대상 데모·오퍼링 수행 (AK홀딩스, AK PLAZA, 제주항공, 애경케미칼, 애경스페셜티, 에어제타 등) 그중 케미칼, 스페셜티, 제주항공 도입 확정
- 애경케미칼 1차 수주로 첫 대외 판매 실현 → 2차 프로젝트로 확장
- AKeeON 솔루션을 통해 Microsoft 솔루션페어 참여

## 기술

Azure OpenAI · Azure AI Search · Azure Container Apps · AWS Bedrock · Python · FastAPI · React · Typescript · MySQL · Redis · LangChain
