## 개요

사내 복지·인사·규정·매뉴얼 문서 기반 대화형 AI 서비스로 시작해, 2026년 그룹사·대외 판매가 가능한 AX 플랫폼(AI Hub · Orchestrator)으로 확장했습니다. 외주 참여 없이 AX사업팀이 자체 개발했고, 2년여 만에 애경그룹의 AI 플랫폼으로 자리잡았습니다.

## 역할

- **사업 기획** — 제품소개서, 가격 모델(라이선스 + Agent 모듈 + 유지보수), 솔루션 소개 영상 기획·편집, 계약 프로세스 수립
- **초기 구축** — Azure OpenAI/AI Foundry + AWS Bedrock LLM 연동, 공통 RAG 모듈, Agent 실행 구조 설계 및 개발
- **관리자 페이지(AKeeON Admin) 기획 총괄** — 권한·파일·비용·대시보드
- **파트너 협업** — 에티버스·클루커스(MSP), AWS·Microsoft

## 성과

- 114건 사내 평가 Dataset 기준 정확도 **95.8%** (Semantic → Hybrid Search 전환, 벡터 코사인 유사도 검증으로 출처 정확도 개선)
- 계열사·대외 고객 대상 데모·오퍼링 수행 (AK홀딩스, AK PLAZA, 제주항공, 애경케미칼, 애경스페셜티, 에어제타)
- 애경케미칼 1차 수주로 첫 대외 판매 실현 → 2차 프로젝트로 확장
- 사내 첫 AI RAG 도입을 위해 Microsoft와 협업, 대표·상무 등 임원진 결과보고

## 기술

Azure OpenAI · Azure AI Search · Azure Container Apps · AWS Bedrock · Python · FastAPI · MySQL · Redis · LangChain
